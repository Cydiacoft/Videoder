# Videoader v26.10.3+6 · Windows x64

本版将媒体探测、编码能力检测、FFmpeg 参数构造与转码执行，以及 yt-dlp/Aria2 的参数、进度和下载执行迁入原生核心。下载、转码和探测共用任务状态记录与取消接口；界面仍负责设置、状态展示和下载成品校验。

## 主要变化

- 下载进度包含速度、ETA、播放列表和合并/后处理阶段；下载结果会验证最终视频文件的音视频流。
- GPU 编码器经过实际试编码验证后才可用；专业工作台的参数限制与基础工具保持一致。
- 原生任务状态可查询，取消可重复调用；日志和事件队列都有上限。
- “关于 Videoader”支持选择更新包下载目录、查看下载进度、取消下载，并在文件大小与 SHA-256 校验通过后保存 ZIP。
- Windows 发行包内包含 `videoder_core.dll`，核心不可用时仍保留兼容执行路径。

## 安装

下载 `Videoader-v26.10.3+6-windows-x64.zip`，完整解压后运行 `videoder_demo.exe`。请保留同目录下的 DLL、`data/`、`LICENSE` 和 `NOTICE`。FFmpeg、ffprobe、yt-dlp 和 Aria2 不随包分发，按需在设置中指定本机路径。
