# Videoder v26.10.3+7 · Windows x64

## 本次更新

- GitHub 仓库更名为 `Cydiacoft/Videoder`，应用更新检查、更新包下载和 README 链接同步指向新地址。
- 新增图像处理工作区：本地图像裁剪、缩放、旋转、PNG/JPEG/WebP 格式转换；视频首帧封面提取；按秒数导出视频画面。
- 图像参数校验与 FFmpeg 命令构造由 C++ 核心处理，通过既有原生任务系统执行、取消和验证输出。原生核心 ABI 更新到 4。
- 更新应用可见名称与文档中的旧称。旧 Release 已清理，本版为新的 Windows 正式发布。

## 安装与使用

下载 `Videoder-v26.10.3+7-windows-x64.zip`，完整解压后运行 `videoder_demo.exe`。保留同目录的 `videoder_core.dll`、`data/`、`LICENSE` 和 `NOTICE`。FFmpeg、ffprobe、yt-dlp 和 Aria2 不随包分发；在设置中配置本机 FFmpeg 后即可使用图像处理。WebP 输出需要 FFmpeg 提供 `libwebp` 编码器。
