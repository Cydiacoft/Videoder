# Videoder v26.10.27+8 · Windows x64

## 更新

- 扩展中心支持签名 VDX 安装、依赖检测、启停、更新、回滚和卸载；随附 yt-dlp 与 TikTokDownloader 1.1.0。
- 图像支持批量裁剪、缩放、旋转、BMP/TIFF 输出、即时预览、结果汇总和重试未完成项目。
- 新增视频静音、水平/垂直镜像、图片水印、字幕导出、音频降噪、音量调整和响度统一。
- 支持本机编辑预设，改善 Cookie 导入、中文文件路径、取消、任务日志及结果体积和耗时展示。

## 使用

下载 `Videoder-v26.10.27+8-windows-x64.zip`，完整解压后运行 `videoder_demo.exe`。保留整个目录，包括核心 DLL、data、LICENSE 和 NOTICE。

FFmpeg、ffprobe、yt-dlp 和 Aria2 不随包分发，请在设置中配置。TikTokDownloader 需要单独配置外部 API 服务。在线扩展目录尚未启用时，可使用随附插件或导入本地 VDX。

附件提供 ZIP 的 SHA-256 校验文件。本版为 Flutter 正式版；原生 WinUI 3 完整迁移在独立 `WinUI3` 分支开发，不影响本版。
